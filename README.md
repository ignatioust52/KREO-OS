# KREO

**MAKE THE WORK. RUN THE BUSINESS. KEEP MOVING.**

KREO is the Business OS for Creatives. It helps creative professionals manage projects, clients, finances, and deliverables all in one place.

## Product Philosophy
Most creative professionals do not struggle only with doing the creative work. They struggle with managing everything surrounding the work (clients in WhatsApp, quotes in Word, expenses in notebooks).

KREO centralizes everything around the **Project**.

## Technology Stack
- **Framework:** Next.js (App Router)
- **Database:** PostgreSQL with Prisma ORM
- **Styling:** Tailwind CSS + shadcn/ui

## Getting Started
1. Install dependencies: `npm install`
2. Set up your `.env` file with `DATABASE_URL`
3. Run database migrations: `npx prisma db push`
4. Start the development server: `npm run dev`

Open [http://localhost:3000](http://localhost:3000) to view KREO.
